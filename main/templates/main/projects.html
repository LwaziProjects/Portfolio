Image Compression Using Wavelet Transform and Huffman Coding

Apr - May 2024

Implemented a comprehensive image compression system using Haar Wavelet Transform and Huffman encoding. The project involved transforming images into matrices, performing multi-level wavelet decomposition, quantization, and encoding/decoding operations while analyzing time and space complexity.

Key Features:
  • Image compression using Haar Wavelet Transform with multi-level decomposition
  • Huffman coding for lossless compression of quantized coefficients
  • Image reconstruction with inverse Haar transform
  • Performance evaluation using MSE, PSNR, Compression Ratio, and BPP metrics
  • Efficient matrix operations for 2×2 sliding block transformations
  • Quantization and dequantization of wavelet coefficients
Technical Implementation:
  • Designed algorithms for LL, LH, HL, and HH coefficient computation
  • Implemented priority queues for Huffman tree construction
  • Analyzed time complexity O(n²log n) and space complexity O(n²)
  • Processed 2ⁿ × 2ⁿ image matrices with non-overlapping blocks
  • Computed compression quality metrics for performance evaluation
Technologies Used:
Python NumPy Algorithms Data Structures Priority Queues Image Processing

Art Gallery Intruder Alarm System

2023

Designed and implemented a comprehensive alarm system for an art gallery using software engineering principles. The project followed complete software development lifecycle from requirements analysis to testing, with full UML documentation.

System States & Operation:
  • Disarmed State: Sensors inactive, waiting for password entry
  • Arming State: 60-second countdown to allow user exit
  • Armed State: All sensors monitored, window/door detection active
  • Disarming State: 60-second window to enter password after door opens
  • Intruder State: Alarm sounds until correct password entered
System Features:
  • Window glass breakage sensor monitoring
  • Magnetic door sensor integration
  • Keypad with 4-digit password authentication
  • External bell box alarm activation
  • Internal buzzer for system feedback
  • Intrusion event recording and logging
  • Time-delayed arming and disarming sequences
Software Engineering Deliverables:
  • Domain Model: Classes, attributes, relationships, and multiplicities
  • Use-Case Model: Actors, use cases, and interaction flows
  • Analysis Model: Boundary, entity, and control classes
  • Sequence Diagrams: Flow of events for each use case
  • Class Analysis: Responsibilities, attributes, and requirements
  • Implementation: Full system developed in C++
  • Testing: Comprehensive black-box acceptance tests
Technologies Used:
C++ UML Object-Oriented Design State Machines Software Testing Requirements Analysis
